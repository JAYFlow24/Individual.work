🎯 Мета роботи

Набуття теоретичних знань і практичних навичок у сфері мережевих технологій, комп’ютерної безпеки та веб-розробки. Формування вміння створювати сучасні веб-сайти з урахуванням принципів адаптивного дизайну, ефективної структури та захисту інформації. Ознайомлення з основами роботи Web-серверів та застосуванням HTML та CSS3

📌 Мета завдання

  1. Побудувати алгоритм для розрахунку середнього доходу домогосподарства на основі вхідних даних (кількість членів сім’ї та загальний дохід).
  2. Реалізувати цей алгоритм у вигляді програми мовою Python або C.
  3. Використати:
    • змінні та типи даних;
    • умовні оператори (if/else);
    • цикли для обробки;
    • функцію для обчислення.

🛠️ Використані технології

  • HTML5 — семантична розмітка
  • CSS3 — стилізація та адаптивність
  • Flexbox & Grid — компонування блоків
  • Google Fonts — сучасні шрифти
  • Media Queries — адаптація під пристрої
  • Git & GitHub — контроль версій
  • VS Code — середовище розробки
  • Figma — дизайн та прототипування
  • DevTools — налагодження та тестування
